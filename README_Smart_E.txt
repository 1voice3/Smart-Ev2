SMART Ev2 - SE (Smart Equipment) Controller Training Simulator
==============================================================

FILES
  index.html          the whole app (data from your 14 Excel files is built in)
  README_Smart_E.txt  this file

UPLOAD TO GITHUB (iPhone-friendly)
  1. Unzip. In your GitHub repo choose Add file > Upload files, upload BOTH files.
  2. Commit. Repo Settings > Pages > Deploy from branch (main, /root).
  3. Open the https://<you>.github.io/<repo>/ link. (It must be named index.html
     for the link to open directly.)
  It also runs by simply opening index.html from Files / a browser.
